# UNITY-3D-RPG
Learning project in UNITY, 3D RPG game based on DND stuff...

We have a capsule player so far, player input movement and 3rd person camera with free look and change of direction with look.

Also the map is generated from FastNoise which you can find here: **[Fast Noise Lite](https://github.com/Auburn/FastNoiseLite)**.

Trees and rocks are written to vector of vectors so no tree or rock can have same place.

We also made boundaries around map so you can never run away :)
